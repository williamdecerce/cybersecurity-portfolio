# Brute Force Log Analysis

## Objective

Analyze authentication logs to identify potential brute-force activity and determine whether suspicious login attempts require investigation.

## Scenario

A security analyst is reviewing authentication logs after an unusual number of failed login attempts was detected.

The goal is to identify suspicious patterns, determine the potential source of the activity, assess the risk, and recommend appropriate response actions.

## Investigation

The investigation will focus on:

- Failed login attempts
- Source IP addresses
- Targeted usernames
- Timestamps
- Repeated authentication attempts
- Successful logins following failed attempts
